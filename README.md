# Budget Tracker

Cross-platform Personal Finance & Habit Tracker built with Kotlin Multiplatform.

## Overview
A professional, production-ready application supporting Android, iOS, Desktop, Web, and Backend synchronization.

## Tech Stack
- **Client**: Kotlin Multiplatform + Compose Multiplatform
- **Shared**: Kotlinx Serialization, Coroutines, Ktor Client
- **Backend**: Ktor Server (migrating to Spring Boot)
- **Database**: SQLDelight / Exposed (planned)
- **DI**: Koin
- **CI/CD**: GitHub Actions

## Getting Started
1. Open in IntelliJ IDEA with Kotlin Multiplatform plugin.
2. Run `./gradlew build`
3. Launch desired run configurations.
